### 🎂 Sobre o projeto

Um site interativo de aniversário, criado como presente surpresa, com galeria de fotos, mensagem/surpresa especial e vídeo comemorativo, tudo em uma experiência web simples e feita à mão.

### 📄 Páginas do site

| Página | Descrição |
|---|---|
| `index.html` | Página inicial do site |
| `galeria.html` | Galeria de fotos especiais |
| `surpresa.html` | A surpresa principal 🎁 |
| `video.html` | Vídeo comemorativo |

### 📁 Estrutura de pastas

```
site-de-aniversario/
├── css/       → estilos do site
├── js/        → scripts e interações
├── midia/     → imagens usadas na galeria
├── video/     → vídeo comemorativo
├── index.html
├── galeria.html
├── surpresa.html
└── video.html
```

<br/>

### 🚀 Como rodar localmente

```bash
git clone https://github.com/dgphaney-dev/site-de-aniversario.git
cd site-de-aniversario
```

Depois é só abrir o `index.html` no navegador — não precisa de servidor nem instalação.
